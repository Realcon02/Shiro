# Shiro

Это многофункциональный Discord-бот, главной фишкой которого является возможность создания подписок на произведения на сайтах RanobeLib и MangaLib.

## Требования

- Docker & Docker Compose

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните поля:
   - `BOT_TOKEN` — токен вашего бота;
   - `UPLOAD_CHANNEL_ID` — ID канала для загрузки обложек, к которому у бота будет доступ.
2. При необходимости отредактируйте `config.py`:
   - `INTERVAL_CHECKING_NEW_CHAPTERS` — интервал между проверками на наличие новых глав (в минутах).

## Управление

Для управления жизненным циклом бота используйте Docker Compose:

### Запуск
```bash
docker compose up --build
```
Для запуска в фоне добавьте флаг `-d`

### Остановка
```bash
docker compose down
```
