# Shiro

Это многофункциональный Discord-бот, главной фишкой которого является возможность создания подписок на произведения на сайтах RanobeLib и MangaLib.

## Требования

- Docker & Docker Compose

## Настройка

1. Скопируйте `.env.example` в `.env` и заполните поля (в частности `BOT_TOKEN`).
2. Отредактируйте `config.py`:
   - замените ID канала для загрузки обложек (`UPLOAD_CHANNEL_ID`) на тот, к которому у бота будет доступ;
   - при необходимости измените интервал между проверками на наличие новых глав.

## Управление

Для управления жизненным циклом бота используйте Docker Compose:

### Запуск
```bash
docker compose up --build
```
Для запуска в фоне добавьте флаг `-d`

### Остановка
```bash
docker compose down
```
